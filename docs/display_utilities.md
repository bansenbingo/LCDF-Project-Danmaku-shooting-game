# DispNum.v — 数码管动态扫描显示模块

## 功能概述

Digitally 工具生成的动态扫描数码管显示模块。通过 2 位扫描信号轮流选中 4 个数码管位，使用 2-4 译码器控制阳极，同时通过多路选择器将对应的 BCD 数据送入 7 段译码器输出段码。

## 结构分析

### 1. 内部子模块

该文件包含 4 个子模块和一个顶层模块：

**Decoder2**：2-4 线译码器
```verilog
assign out_0 = (sel == 2'h0) ? 1'b1 : 1'b0;
```
根据 2 位选择信号输出 4 个独热控制信号。

**mux4to1**：4 选 1 多路选择器（1 位）
```verilog
assign O = ((~S[0] & ~S[1]) & I[0]) | ((~S[1] & S[0]) & I[1]) | ...;
```
标准选择逻辑，输出逻辑表达式。

**mux4to1b4**：4 选 1 多路选择器（4 位宽）
展开为 4 个独立的 1 位 mux，每位独立选择。

**MyMC14995**：7 段译码器（MC14495 兼容）
- 输入：4 位 BCD 数据（D0-D3）、锁存使能 LE、小数点 point
- 输出：8 段信号（a-g + p），低有效
- 包含完整的大写字母 0-9 译码逻辑
- LE=1 时所有段熄灭

### 2. 顶层 DispNum 模块

```
HEXS[15:0] ──→ mux4to1b4 ──→ MyMC14995 ──→ SEGMENT[7:0]
                                     ↑
point[3:0]  ──→ mux4to1 ─────────────┤
LES[3:0]    ──→ mux4to1 ─────────────┤
                                     │
scan[1:0]   ──→ Decoder2  ──→ AN[3:0] (反相输出)
```

**工作流程**：
1. `scan` 信号控制当前扫描到哪个数码管位（0-3 循环）
2. `Decoder2` 输出阳极控制信号并经反相器输出到 `AN`
3. `mux4to1b4` 从 4 组 4 位 BCD 数据中选出当前位的数据
4. `mux4to1` 从 4 位小数点信号中选出对应位的小数点
5. `mux4to1` 从 4 位 LE 信号中选出对应位的锁存使能
6. `MyMC14995` 将 BCD 码转换为 7 段码输出到 `SEGMENT`

### 3. 接口

- `scan[1:0]`：扫描选择（通常接时钟分频器的高位）
- `HEXS[15:0]`：4 位十六进制数据（每位 4-bit BCD）
- `point[3:0]`：小数点控制（每位 1-bit）
- `LES[3:0]`：锁存使能（每位 1-bit，控制是否灭灯）
- `AN[3:0]`：阳极输出（低有效，选中位为低）
- `SEGMENT[7:0]`：段码输出（a-g + dp）

# SegmentDecoder.v — 单 digit 7 段译码器

## 功能概述

将 4 位十六进制数转换为 7 段数码管的段选信号。支持 0-9 和 A-F 的显示，低有效输出。

## 结构分析

### 1. 译码逻辑

```verilog
case(hex)
    4'h0: segment[6:0] <= 7'b1000000;  // 0：各段 a-f 亮
    4'h1: segment[6:0] <= 7'b1111001;  // 1：仅 b, c 亮
    4'h2: segment[6:0] <= 7'b0100100;  // 2
    ...
endcase
```

`segment[6:0]` 对应 a-g 段顺序，具体映射依赖外部连接：
- 0 表示亮（低有效），1 表示灭
- 通过组合逻辑（case 语句）实现 16 个字符的完整译码表

输出为寄存型 (`output reg`)，使用 `always @*` 组合逻辑块确保实时响应输入变化。

# Seg7Decode.v — 8 位 7 段译码器

## 功能概述

将 32 位十六进制数据（8 位数字）译码为 64 位段选信号，同时处理小数点（point）和锁存使能（LE）。

## 结构分析

### 1. 级联结构

实例化 8 个 `SegmentDecoder` 模块，每个处理 4 位数据：
```verilog
SegmentDecoder
    U0(.hex(hex[3:0]),   .segment(digits[6:0])),
    U1(.hex(hex[7:4]),   .segment(digits[14:8])),
    ...
    U7(.hex(hex[31:28]), .segment(digits[62:56]));
```

### 2. 小数点处理

`digits` 的最高位（第 7 位的 bit 7）被赋值为 `~point` 的对应位（低有效）。

### 3. LE 锁存使能

```verilog
assign pattern[7:0] = digits[7:0] | {8{LE[0]}};
```

当 `LE[i]=1` 时，对应位的段码全为 1（全灭），实现数码管锁存熄灭功能。

### 4. 输出格式

`pattern[63:0]` 包含 8 组 8 位段码（含小数点位），每组格式：`{dp, a, b, c, d, e, f, g}`。

# Seg7Remap.v — 7 段显示位重映射

## 功能概述

针对具体硬件布线，将 32 位输入数据按照数码管段选的实际物理连接重新排序为 32 位输出数据。

## 结构分析

### 1. 重映射逻辑

采用纯组合逻辑的位级重排列：
```verilog
assign O[7:0]  = {I[24], I[12], I[5], I[17], I[25], I[16], I[4], I[0]};
assign O[15:8] = {I[26], I[13], I[7], I[19], I[27], I[18], I[6], I[1]};
assign O[23:16] = {I[28], I[14], I[9], I[21], I[29], I[20], I[8], I[2]};
assign O[31:24] = {I[30], I[15], I[11],I[23], I[31], I[22], I[10],I[3]};
```

每一组 8 位输出从 32 位输入中提取不同位置的位重新组合。目的是使 PCB 布线时的信号交叉得到补偿，确保数码管显示正确。

# Seg7Device.v — 7 段显示设备顶层

## 功能概述

7 段数码管显示子系统的顶层模块，集成译码、重映射、串行移位输出和动态扫描控制。同时输出两种显示接口：直接动态扫描（segment/anode）和串行 P2S 移位输出（sout）。

## 结构分析

### 1. 子模块集成

```
data[31:0] ──→ Seg7Decode ──→ dispData[63:0] ──→ ShiftReg ──→ sout[3:0]
      │              ↑ point, LE(与 blink 门控)
      │              │
      └──→ Seg7Remap ──→ dispPattern[31:0] ──→ 动态扫描 ──→ segment[7:0]
                                                           ──→ anode[3:0]
```

### 2. 串行输出通道

- 64 位数据通过 `ShiftReg` 串行输出
- `sout` 包含 4 个控制信号：`sck`（时钟）、`sdat`（数据）、`oe`（输出使能）、`clrn`（清除）

### 3. 动态扫描通道

使用 `clkScan[1:0]` 控制扫描顺序，`case` 语句轮流选中四个数码管位：

| clkScan | 阳极 | 段码来源 |
|---------|------|----------|
| 00 | 1110（位0亮） | dispPattern[7:0] 取反 |
| 01 | 1101（位1亮） | dispPattern[15:8] 取反 |
| 10 | 1011（位2亮） | dispPattern[23:16] 取反 |
| 11 | 0111（位3亮） | dispPattern[31:24] 取反 |

段码取反是因为硬件使用共阳极数码管（低有效段选）。

### 4. 闪烁控制

`LES = point & {8{clkBlink}}`：通过 `clkBlink` 信号的门控，在闪烁时钟为低时关闭所有段显示，实现数码管闪烁效果。

# ShiftReg.v — 串行移位寄存器

## 功能概述

参数化的并行转串行移位寄存器，用于 LED 和数码管的串行 P2S（Parallel-to-Serial）级联输出。支持自动加载和移位时序控制。

## 结构分析

### 1. 参数定义

- `WIDTH = 16`：数据位宽（可配置）
- `DELAY = 12`：加载间隔时钟周期数

### 2. 输出控制信号

```verilog
assign sout = {sck, sdat, oe, clrn};   // 4 位控制总线
```

- `sck`：移位时钟（`~clk & sckEn`），仅在移位期间有效
- `sdat`：串行数据输出（`shift[WIDTH]`）
- `oe`：输出使能寄存器
- `clrn`：始终为 1（不清除）

### 3. 状态机

采用单个 `always @(posedge clk)` 块实现：

**加载阶段**（`sckEn=0`，即移位寄存器为空）：
- `counter` 从 -1 开始每个时钟递增
- 当 `counter` 所有位为 1 时（`&counter`），将 `pdata` 加载到 `shift` 寄存器，末尾加 `1'b1` 作为结束标记，`oe=0`
- 加载前 `oe=1`（输出禁用）

**移位阶段**（`sckEn=1`）：
- 每个时钟周期右移一位，补 0
- `sck` 输出移位时钟脉冲
- `sdat` 输出最高位数据

循环往复，实现持续的数据刷新。
