# game_defs.vh — 全局宏定义头文件

## 功能概述

该项目所有模块共享的全局常量定义文件，通过 `include "game_defs.vh"` 引入。涵盖屏幕参数、颜色定义、游戏状态、难度等级、实体数量限制以及各类游戏平衡参数。

## 结构分析

### 1. 屏幕几何参数

```verilog
`define SCREEN_W  640
`define SCREEN_H  480
`define X_BITS    10
`define Y_BITS    9
```

定义了 VGA 显示区域为 640×480 分辨率，X 坐标用 10 位表示，Y 坐标用 9 位表示。

### 2. 颜色定义（BGR 4:4:4 格式）

ZJU VGA 规范要求使用 BGR 色彩顺序，`d_in = {B[3:0], G[3:0], R[3:0]}`。定义了常用 12 位颜色常量：黑、白、红、绿、蓝、黄、青、品红、灰（深/浅）、橙、棕、紫、粉、暗红、暗绿、暗蓝等。

### 3. 游戏状态机编码

- `STATE_MENU` (0)：菜单界面
- `STATE_PLAYING` (1)：游戏中
- `STATE_PAUSED` (2)：暂停
- `STATE_GAMEOVER` (3)：游戏结束
- `STATE_WIN` (4)：胜利

### 4. 难度等级

- `DIFF_EASY` (0)：简单
- `DIFF_NORMAL` (1)：普通
- `DIFF_HARD` (2)：困难
- `DIFF_HELL` (3)：地狱

### 5. 实体数量上限

- 最大敌人数量：8
- 最大玩家子弹：16
- 最大敌人子弹：64
- 最大障碍物：8

### 6. 玩家参数

- 战机尺寸：半宽 16px，高度 24px
- 移动速度：2 像素/帧
- 默认生命值：3
- 射击间隔：4 帧（60Hz 下）
- 无敌时间：180 帧（3 秒）
- 子弹速度：8 像素/帧

### 7. 敌人参数

- 刷新间隔：120 帧（2 秒）
- 射击间隔基数：60 帧（1 秒）
- 子弹速度：2 像素/帧
- 尺寸：半宽 14px，半高 10px

### 8. 子弹类型

直射、抛物线、顺时针圆弧、逆时针圆弧共 4 种类型。

### 9. 计分与计时

- 分数胜利目标：500 分
- 开局无敌时间：300 帧
- 结束显示时长：300 帧
- 暂停冷却时间：300 帧

### 10. 七段数码管显示模式

击杀数、生命值、分数三种可切换模式。

# game_top.v — FPGA 顶层模块

## 功能概述

整个弹幕射击游戏的 FPGA 顶层集成模块，负责连接所有子系统：时钟分频、PS/2 键盘输入、VGA 渲染管线、游戏逻辑引擎、七段数码管显示（直连与串行 P2S）以及 LED 输出。

## 结构分析

### 1. 端口定义

顶层端口严格匹配 K7 开发板的 XDC 约束文件：

- 系统时钟 `clk`（100MHz，AC18 引脚）与复位 `rstn`（低有效，W13 引脚）
- VGA 输出：`r[3:0]`、`g[3:0]`、`b[3:0]` 以及行/场同步信号 `hs`/`vs`
- PS/2 键盘：`ps2_clk`、`ps2_data`
- 七段数码管：直连输出 `SEGMENT[7:0]` + `AN[3:0]`，串行 P2S 输出 `SEG_CLK/DT/EN/CLR`
- LED：直连 `LED[7:0]`，串行 P2S 输出 `LED_CLK/DT/EN/CLR`

### 2. 时钟分频器

32 位自由运行计数器 `clkdiv`，在 100MHz 时钟下持续累加：

- `clkdiv[1]` 提供 25MHz 给 VGA
- `clkdiv[3]` 提供约 6.25MHz 给串行移位寄存器
- `clkdiv[15:14]` 提供扫描信号给数码管动态扫描

### 3. 子系统互联

采用"逻辑引擎 → 状态信号 → 渲染管线"的数据流架构：

```
Keyboard (PS/2) ──→ key_data/key_diff ──→ Game Logic ──→ VGA Top (Rendering)
                        ↑                        ↓
                        └──── frame_tick ─────────┘
```

- **Keyboard** 模块解析 PS/2 协议，输出按键状态位图、难度选择和模式/循环切换信号
- **Game Logic** 接收按键输入和帧同步信号，管理游戏状态机，输出所有实体的位置和状态
- **VGA Top** 接收游戏状态，驱动所有渲染器产生像素数据，同时生成 `frame_tick`（60Hz 帧脉冲）

### 4. 七段数码管子系统

- **直连模式**：通过 `DispNum` 模块实现 4 位数码管动态扫描显示，显示内容由 `seg_mode` 选择（分数/击杀/生命）
- **串行 P2S 模式**：通过 `Seg7Device` + `ShiftReg` 实现串行移位输出，支持 8 位数码管级联

### 5. LED 输出

- 直连 LED 显示游戏数据的溢出高位
- 串行 P2S 通过 `ShiftReg` 输出，用于扩展 LED 显示
