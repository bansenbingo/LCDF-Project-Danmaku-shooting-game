# player_render.v — 玩家战机渲染器

## 功能概述

纯组合逻辑渲染器，绘制玩家飞机图形。飞机为向上的等腰三角形，包含主体、驾驶舱、机翼细节和引擎发光效果。支持无敌闪烁显示。

## 结构分析

### 1. 几何造型

飞机为一个底朝下的等腰三角形，顶点坐标：
- 顶点（机头）：`(px, py - 12)`
- 左底角：`(px - 16, py + 12)`
- 右底角：`(px + 16, py + 12)`

采用边检测法判断像素是否在三角形内部：
- 左边界检测：`3×|dx| - 2×(dy+12) ≤ 24`，通过 `w_check = 3×adx` 与 `w_limit = 2×(dy+12)` 比较实现
- 垂直边界限制：`dy ∈ [-12, +12]`

### 2. 细节分层

通过嵌套的条件判断实现不同颜色区域的叠加：

| 区域 | 条件 | 颜色 |
|------|------|------|
| 引擎发光 | `dy ∈ [8,11]`, `adx ∈ [5,8]` | 橙色 |
| 驾驶舱 | `dy ∈ [-12,-2]` 且 `6×adx ≤ 2×(dy+12)` 且 `ady > 1` | 深蓝色 |
| 机翼 | `dy ∈ [5,11]`, `adx ∈ [14,18]` | 白色 |
| 主体 | 三角形内部其余区域 | 青色 |

### 3. 无敌闪烁

- `flash` 输入由游戏逻辑控制，在无敌期间周期性闪烁（每 2-4 帧切换）
- 当 `flash=0` 时战机完全不可见（`hit=0`），实现闪烁效果
- `alive=0` 时战机也不渲染

### 4. 颜色输出

按优先级从高到低：引擎 > 驾驶舱 > 机翼 > 主体。输出标准 12 位 BGR 格式颜色值。

# enemy_render.v — 敌人 UFO 渲染器

## 功能概述

纯组合逻辑渲染器，绘制飞碟形敌人。主体为椭圆，包含驾驶舱穹顶、边缘轮廓、舷窗等细节。HP 值影响颜色强度，被击中时有白色闪烁效果。

## 结构分析

### 1. 椭圆形体绘制

采用椭圆方程 `x²/a² + y²/b² ≤ 1` 判断像素是否在 UFO 体内。使用简化近似公式 `dx² + 2×dy² ≤ 200`（a≈14, b≈10）。

关键位宽约束：
- `adx2[21:0]`、`ady2[21:0]`：22 位宽，足以容纳 `adx²` 的理论最大值 `640² = 409600`（需 19 位），避免 16 位截断导致的乘法溢出（溢出会在距敌机约 256 像素处产生周期性鬼影点）
- `dist2[22:0]`：23 位宽，与 `adx2` 匹配
- 阈值比较字面量统一为 `23'd*` 宽度

### 2. 细节分层

| 区域 | 条件 | 说明 |
|------|------|------|
| 舷窗（眼） | `dy ∈ [-6,-2]`, `adx ∈ [2,6]` | 小方形窗口，纯坐标判定无乘法 |
| 穹顶 | `dy < 0`, `ady ≤ 6`, `adx ≤ 8`，`9×dx² + 16×dy² ≤ 576` | 上半部的驾驶舱穹顶，坐标门控保护乘法不溢出 |
| 边缘轮廓 | `170 ≤ dist2 ≤ 200` | 薄椭圆环（2 像素宽），颜色随 HP 变化 |
| 主体 | `dist2 ≤ 200` | 整个椭圆区域 |

### 3. HP 分级着色

根据剩余 HP 改变颜色方案，让玩家直观感受到敌人强度的变化：

| HP | 主体颜色 | 穹顶颜色 | 轮廓颜色 |
|----|----------|----------|----------|
| 3 | 品红 | 白色 | 黄色 |
| 2 | 紫色 | 浅灰 | 青色 |
| 1 | 暗红 | 灰色 | 暗绿 |

### 4. 击中闪烁

`flash` 信号有效时强制输出白色（覆盖所有颜色），持续 2 帧后自动清除，提供视觉反馈。

# bullet_render.v — 子弹渲染器

## 功能概述

纯组合逻辑渲染器，可同时用于渲染玩家子弹和敌人子弹。通过 `is_player` 参数区分子弹类型，玩家子弹为青色小菱形，敌人子弹为红色小方块。

## 结构分析

### 1. 统一接口设计

单个模块通过参数化支持两种子弹类型：

- `bx[9:0]` / `by[8:0]`：子弹中心坐标
- `active`：子弹是否激活
- `is_player`：1=玩家子弹, 0=敌人子弹
- `btype[1:0]`：子弹类型（预留，影响形状）

### 2. 几何形状

**玩家子弹（菱形）**：
- 曼哈顿距离判定：`adx + ady ≤ 2`
- 对角 45 度的菱形形状，大小约 5×5 像素

**敌人子弹（方块）**：
- 矩形判定：`adx ≤ 1 && ady ≤ 1`
- 标准 3×3 像素方块

### 3. 颜色方案

- 玩家子弹：青色（`COL_CYAN`）
- 敌人子弹：红色（`COL_RED`）

### 4. 实现细节

- 通过补码取绝对值计算曼哈顿距离：`adx = dx[10] ? (~dx+1) : dx`
- 使用带符号扩展的 11 位运算避免溢出
- 仅在 `active` 为高时输出命中信号
