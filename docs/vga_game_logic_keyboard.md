# vga_top.v — VGA 渲染管线顶层

## 功能概述

VGA 渲染管线的顶层模块，负责生成 25MHz 像素时钟、驱动 VGA 控制器、生成帧同步脉冲、实例化所有实体渲染器并进行优先级多路选择（Priority MUX），最终输出像素颜色数据。

## 结构分析

### 1. 25MHz 像素时钟生成

```verilog
reg [1:0] cdiv;
always @(posedge clk_100m) cdiv <= cdiv + 1'b1;
wire vga_clk = cdiv[1];   // 100MHz ÷ 4 = 25MHz
```

通过 2 位计数器对 100MHz 系统时钟进行 4 分频，得到 25MHz 的 VGA 像素时钟。

### 2. VGA 控制器（vgac）

实例化 `vgac` 模块，输入 25MHz 像素时钟和复位信号，输出：
- `row_addr[8:0]`：当前像素行地址（0-479）
- `col_addr[9:0]`：当前像素列地址（0-639）
- `rdn`：读使能（低有效，消隐期间为高）
- `r/g/b[3:0]`：RGB 颜色分量
- `hs/vs`：行/场同步信号

### 3. 帧同步脉冲生成

```verilog
reg [2:0] vs_sync;
always @(posedge clk_100m) vs_sync <= {vs_sync[1:0], vs};
wire vs_fall = vs_sync[2] && !vs_sync[1];  // vs 下降沿检测
```

通过三级同步器在 100MHz 时钟域中检测 `vs` 的下跳沿（场同步开始），生成一个时钟周期的 `frame_tick` 脉冲。该脉冲在 V-blank 期间触发，保证游戏状态更新不会造成画面撕裂。

### 4. 实体渲染器实例化

所有渲染器均为纯组合逻辑，在同一个 25MHz 像素时钟域中并行计算：

| 渲染器 | 实例数 | 说明 |
|--------|--------|------|
| `player_render` | 1 | 玩家战机渲染 |
| `enemy_render` | 8（generate） | 敌人 UFO 渲染 |
| `bullet_render`（玩家） | 16（generate） | 玩家子弹渲染（青色菱形） |
| `bullet_render`（敌人） | 64（generate） | 敌人子弹渲染（红色方块） |
| `hud_render` | 1 | HUD 信息叠加 |
| `menu_render` | 1 | 菜单界面渲染 |

每个实体渲染器输出两个信号：
- `hit`：当前像素是否属于该实体
- `color[11:0]`：该像素的 BGR 颜色值

### 5. 优先级多路选择器（Priority MUX）

```
菜单（仅在 STATE_MENU）
  ↓
HUD 信息层
  ↓
玩家战机
  ↓
玩家子弹
  ↓
敌人子弹
  ↓
敌人
  ↓
背景（黑色）
```

通过级联的 `if-else` 优先级链：消隐期间强制输出黑色（保护 VGA 电平），菜单仅在菜单状态下显示；其余层级按 HUD > 玩家 > 玩家子弹 > 敌人子弹 > 敌人 > 背景的顺序输出。每个实体类别内部也采用优先级编码（最低索引优先）。

# vgac.v — VGA 控制器

## 功能概述

标准 640×480@60Hz VGA 时序控制器。生成行/列扫描地址、读写使能信号以及行/场同步信号，并通过 `d_in` 输入 12 位 BGR 像素数据输出到 RGB 颜色通道。

## 结构分析

### 1. 水平计数器（h_count）

VGA 水平时序参数（640×480@60Hz）：
- 一行总计 800 个像素时钟周期
- h_count 范围：0 ~ 799
- 有效显示区：144 ~ 783（640 个像素）
- 行同步脉冲：h_count > 95 时输出高

### 2. 垂直计数器（v_count）

- 一帧总计 525 行
- v_count 范围：0 ~ 524
- 有效显示区：35 ~ 514（480 行）
- 场同步脉冲：v_count > 1 时输出高

### 3. 地址生成

```verilog
wire [9:0] row = v_count - 10'd35;   // 行地址（0-479，有效区偏移）
wire [9:0] col = h_count - 10'd143;  // 列地址（0-639，有效区偏移）
```

通过减去消隐偏移量，将原始计数器值转换为实际像素坐标。

### 4. 读使能与像素输出

- `read` 信号在有效显示区域内为高
- `rdn = ~read`（低有效读使能）
- 消隐期间（`rdn=1`）强制输出黑色（`r=g=b=0`）

### 5. 同步信号

- `hs`：行同步，h_count > 95 时为高
- `vs`：场同步，v_count > 1 时为高

上述信号均在 `vga_clk` 上升沿通过寄存器锁存后输出，保证时序稳定性。

# game_logic.v — 游戏逻辑核心

## 功能概述

游戏的核心状态机与实体管理模块。运行在 60Hz 帧同步下，完全由键盘控制（无物理开关/按键）。负责管理游戏状态转换、玩家移动与射击、敌人刷新与行为模式、子弹运动、碰撞检测、武器升级以及计分系统。

## 结构分析

### 1. 状态机设计

五状态 FSM：

```
MENU ──[Start]──→ PLAYING ──[Die]──→ GAMEOVER ──[Timer]──→ MENU
                    ↑  ↓                     │
                    │  ├──[Pause]──→ PAUSED  │
                    │  └──[Win] ──→ WIN ─────┘
                    └─────────────────────────┘
```

### 2. 按键采集系统

采用"边沿检测 + 锁存"机制处理一次性按键事件：

- 每个特殊按键（暂停 P、升级 K、模式 M、循环 Tab）在时钟上升沿检测正跳变
- 检测到跳变后置位锁存器，保持直到帧 tick 消费并清除
- 持续按键（方向、射击）直接读取按键状态位图

### 3. 实体数据存储

所有实体状态使用扁平化位域打包存储，便于综合优化：

| 实体类型 | 数量 | X 坐标 | Y 坐标 | 其他 |
|----------|------|--------|--------|------|
| 玩家 | 1 | 10 位 | 9 位 | HP(3b)、武器等级(2b) |
| 敌人 | 8 | 80 位 | 72 位 | HP(16b)、方向(8b)、射击CD(64b)、相位(64b) |
| 玩家子弹 | 16 | 160 位 | 144 位 | 活跃(16b) |
| 敌人子弹 | 64 | 640 位 | 576 位 | 活跃(64b) |

使用 Verilog 的位选择语法 `[i*N +: N]` 提取打包字段，通过辅助函数 `get_en_x(i)` 和 `get_en_y(i)` 简化访问。

### 4. LFSR 伪随机数生成

16 位 LFSR，多项式 `x^16 + x^15 + x^13 + x^4 + 1`（反馈抽头 16'hB400）。每个游戏 tick 更新一次，用于实现随机的敌人刷新位置、HP、射击间隔和移动相位。

### 5. 菜单状态

- 通过键盘 1-4 选择四个难度等级
- 通过 M 键切换模式（积分/无尽）
- 按 J/空格/回车开始游戏
- 根据选择初始化玩家 HP 等参数

### 6. 游戏进行状态（核心逻辑）

**玩家控制**：
- WASD 方向键移动，速度和边界限制在可移动范围内（X: 40~600, Y: 40~430）
- 按住 Shift 进入低速模式（慢走）
- 按 J/空格/回车射击，支持最多 3 路子弹（取决于武器等级）
- 无敌保护机制（受伤后 180 帧闪烁无敌）

**敌人刷新**：在状态计时器归零后开始刷新。遍历 8 个敌人槽位，在空闲槽位生成新敌人。HP 根据难度等级随机生成（Easy=1, Normal=1, Hard=1~2, Hell=2~3）。

**敌人行为（8 种独特 AI 模式）**：
1. **敌人 0**：快速下降 + 宽幅振荡，三路散射
2. **敌人 1**：停在 Y=80 处，窄幅振荡，三路散射，定时自毁
3. **敌人 2**：停在 Y=60 处，向玩家漂移，三路瞄准射击
4. **敌人 3**：对角线入场 + 振荡，双路快速射击
5. **敌人 4**：快速下降 + 振荡，三路散射
6. **敌人 5**：慢速下降 + 抖动漂移，双路射击
7. **敌人 6**：中速下降 + 振荡，双路射击
8. **敌人 7**：侧向快速入场，对角线然后反向

每种敌人的移动速度、相位增量、射击模式各不相同，提供多样化的游戏体验。

**碰撞检测**：
- 玩家子弹 vs 敌人：HP 制多段命中（敌人 5/6/7 为 1HP 即死，敌人 0-4 支持多段伤害），击杀时增加分数和击杀数
- 敌人子弹 vs 玩家：检查所有已发射的敌人子弹槽位，命中扣血并触发无敌
- 玩家 vs 敌人接触：直接碰撞伤害

**武器升级**：击杀数达到阈值（10/20/40...）时自动提升武器等级（最大 3 级），增加子弹数量和射击通道。

### 7. 暂停/游戏结束/胜利状态

- 暂停：按 P 或射击键恢复
- 游戏结束：显示 5 秒后返回菜单
- 胜利（积分模式达到目标分数）：显示 5 秒后返回菜单

### 8. 七段数码管输出

通过 `seg_cycle` 循环切换显示击杀数、生命值或分数。分数/击杀数溢出时在 LED 上显示高位。

# Keyboard.v — PS/2 键盘接口

## 功能概述

PS/2 键盘协议解析模块，将 PS/2 物理层信号解码为游戏可控的按键状态位图。支持方向键（WASD）、功能键（J/K/P/Shift）、难度选择键（1-4）、模式切换键（M/Tab）以及扩展键码处理。

## 结构分析

### 1. PS/2 物理层接收器（ps2_drive）

内部子模块，实现 PS/2 通信协议的数据接收：

- **同步检测**：对 `ps2_clk` 进行三级同步采样，检测下降沿作为采样点
- **11 位帧结构**：1 起始位(低) + 8 数据位 + 1 奇偶校验位 + 1 停止位(高)
- **FIFO 缓冲**：8 深度的 FIFO 队列，暂存接收到的字节
- **溢出检测**：当 FIFO 满且继续写入时置位溢出标志
- **读取控制**：`rdn=0` 时从 FIFO 读取一个字节

### 2. 主状态机

PS/2 通码/断码解析的五状态 FSM：

```
RESET ──→ READ ──[0xF0]──→ BREAK ──[任意码]──→ READ
            │                  ↑
            ├──[0xE0]──→ EXT ──┘
            │             │
            │     ┌──[0xF0]──→ EXT_BREAK ──[任意码]──→ READ
            │     │
            └─────┘
```

- **STATE_READ**：读取通码，匹配按键后置位状态位图
- **STATE_BREAK**：断码处理，收到 `0xF0` 后读取下一个字节，清除对应按键状态
- **STATE_EXT**：扩展键码处理，收到 `0xE0` 前缀后进入
- **STATE_EXT_BREAK**：扩展断码处理（`0xE0 0xF0` 序列）

### 3. PS/2 Set 2 键码映射

| 按键 | PS/2 码 | 功能 |
|------|---------|------|
| W | 0x1D | 向上移动 |
| A | 0x1C | 向左移动 |
| S | 0x1B | 向下移动 |
| D | 0x23 | 向右移动 |
| J | 0x3B | 射击/开始 |
| Space | 0x29 | 射击/开始 |
| Enter | 0x5A | 射击/开始 |
| K | 0x42 | 武器升级 |
| P | 0x4D | 暂停 |
| Shift | 0x12 | 低速移动 |
| 1 | 0x16 | 难度：简单 |
| 2 | 0x1E | 难度：普通 |
| 3 | 0x26 | 难度：困难 |
| 4 | 0x25 | 难度：地狱 |
| M | 0x3A | 模式切换 |
| Tab | 0x0D | 显示切换 |

### 4. 输出信号

- `status[7:0]`：8 位按键状态位图，`[0]=上, [1]=下, [2]=左, [3]=右, [4]=射击, [5]=升级, [6]=暂停, [7]=Shift`
- `diff_key[3:0]`：独热编码的难度选择
- `mode_key`：M 键按下标志（持续）
- `cycle_key`：Tab 键按下标志（持续）
