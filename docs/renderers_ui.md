# menu_render.v — 菜单界面渲染器

## 功能概述

纯组合逻辑渲染器，负责渲染游戏开始前的菜单/标题界面。包含游戏标题、装饰边框、"START"提示框、难度选择和模式选择显示、以及操作说明文字。

## 结构分析

### 1. 字符 ROM（Distributed Memory）

通过 Xilinx Distributed Memory Generator 生成的 `ROM_f` IP 核实现字库存储。不再使用硬编码的 `case` 组合逻辑查找表，改为 ROM 读取：

```verilog
ROM_f u_font_rom (
    .a  ({char_code[5:0], sy[2:0]}),   // 9-bit 地址: 高6位=字符编码, 低3位=像素行
    .spo(char_bitmap)                   // 8-bit 位图行数据
);
```

- 地址格式：`{char_code[5:0], sy[2:0]}`（9 位，共 512 深度）
- 字符映射：A-Y, 0-9, 空格(36), 冒号(37), 减号(40), 点号(42)
- 位图数据来源：`i.coe` 初始化文件（与 `hud_render.v` 共用同一 ROM IP）
- `char_code` 为 6 位宽，可正确表达 0-42 的全部字符编码

### 2. 菜单布局

矩形区域结构（640×480 画布内）：

```
┌─────────────────────────────────────┐  y=40
│  ┌─────────────────────────────┐    │
│  │      彩色装饰边框               │    │  y=80~440
│  │                               │    │
│  │    AEROPLANE (标题第一行)      │    │  y=96
│  │    DANMAKU SHOOTING (标题第二行)│    │  y=104
│  │                               │    │
│  │    ┌──────────────────┐       │    │  y=184
│  │    │     START        │       │    │  (高亮框)
│  │    └──────────────────┘       │    │
│  │                               │    │
│  │    DIFFICULTY: EASY           │    │  y=304
│  │    MODE:     SCORE            │    │  y=320
│  │                               │    │
│  │    WASD: MOVE  J-: FIRE...    │    │  y=360
│  │    P: PAUSE  M: MODE...       │    │  y=376
│  │    1-4: DIFFICULTY  ENTER:..  │    │  y=392
│  │    PRESS ENTER TO START       │    │  y=408
│  └─────────────────────────────┘    │
└─────────────────────────────────────┘  y=440
```

### 3. 装饰边框

双层矩形框，位于中央区域（x: 80~560, y: 40~440）：
- **外层边缘**：6 像素宽，颜色按 `sx[5:3] + sy[5:3]` 切换（青/品红/黄交替），产生彩虹边框效果
- **内层装饰线**：浅灰色细线
- 边框仅在外层和内层边缘渲染，中间为透明

### 4. 标题文字

两行 ASCII 文本，使用多个字符索引组合而成：
- 第一行："AEROPLANE"（9 个字符）
- 第二行："DANMAKU SHOOTING"（16 个字符）

通过字库查找表逐字符输出像素位图。

### 5. 难度与模式选择

- "DIFFICULTY:" + 当前难度值（EASY/NORMAL/HARD/HELL），难度值以青色高亮显示
- "MODE:" + 当前模式值（SCORE/ENDLESS），模式值以绿色高亮显示

### 6. 操作提示

四行文字说明按键映射和操作方式，以深灰色渲染：
- WASD: 移动 | J/Space: 射击 | K: 升级
- P: 暂停 | M: 模式 | Tab: 显示切换
- 1-4: 难度 | Enter: 开始
- PRESS ENTER TO START

### 7. 颜色方案

| 元素 | 颜色 |
|------|------|
| 彩色边框 | 青/品红/黄交替 |
| 内层装饰线 | 浅灰 |
| 标题和标签 | 白色 |
| START 文字 | 黄色 |
| START 框填充 | 深灰 |
| 难度值 | 青色 |
| 模式值 | 绿色 |
| 操作提示 | 深灰 |

# hud_render.v — HUD 信息叠加渲染器

## 功能概述

纯组合逻辑渲染器，负责在游戏进行中叠加 HUD（抬头显示）信息。显示分数（SCORE:...）、生命值（HP:X）、暂停图标（||）、游戏结束文字（GAME OVER）和胜利文字（YOU WIN）。

## 结构分析

### 1. 字符 ROM（Distributed Memory）

与 `menu_render.v` 共用同一个 `ROM_f` IP 核，通过 Distributed Memory Generator 实现。字库包含更大的字符集：

```verilog
ROM_f u_font_rom (
    .a  ({char_code[5:0], sy[2:0]}),   // 9-bit 地址
    .spo(char_bitmap)                   // 8-bit 位图行数据
);
```

- 字符映射：A-Z(0-25), 0-9(26-35), 空格(36), 冒号(37), 竖线\|(39), X(23)
- 位图数据来源：`i.coe` 初始化文件（根目录）
- `char_code` 为 6 位宽（从旧版 5 位升级），避免编码 ≥32 时截断

### 2. 分数显示

- 位置：右下区域 `(400, 456)`
- 格式：`SCORE:` + 8 位十六进制数字
- 宽度：14 字符 × 8 像素 = 112 像素
- 分数值为 20 位，直接拆分为高位半字节显示，低 4 位做近似 BCD 处理
- 仅在游戏进行和暂停状态下显示

### 3. 生命值显示

- 位置：左上角 `(8, 8)`
- 格式：`HP:X`
- 宽度：4 字符 × 8 像素 = 32 像素
- 仅在游戏进行和暂停状态下显示

### 4. 暂停图标

- 位置：右下区域 `(600, 456)`
- 格式：`||`（双竖线符号）
- 仅在暂停状态下显示
- 暂停图标使用黄色渲染以区别于分数（白色）

### 5. 游戏结束画面

- 居中显示大号文字
- 第一行：`GAME`（4 字符，x=272, y=200，框高 8 像素 = 1 个字符高度）
- 第二行：`OVER`（4 字符，x=272, y=216，框高 8 像素）
- 颜色：红色
- 仅在 `STATE_GAMEOVER` 状态下显示

### 6. 胜利画面

- 居中显示大号文字
- 第一行：`YOU`（3 字符，x=280, y=200，框高 8 像素）
- 第二行：`WIN`（3 字符，x=280, y=216，框高 8 像素）
- 颜色：绿色
- 仅在 `STATE_WIN` 状态下显示

### 7. 颜色优先级

```verilog
color = go_any    ? RED    :   // 游戏结束最高优先级
        yw_any    ? GREEN  :   // 胜利次之
        pause_hit ? YELLOW :   // 暂停图标
                    WHITE;     // 分数和HP默认白色
```
