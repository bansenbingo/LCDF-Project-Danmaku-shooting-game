## 1. 系统概述

本游戏是一款基于 **Xilinx K7 FPGA (xc7k160tffg676-1)** 平台开发的 VGA 弹幕射击游戏。游戏以 640×480 @ 60Hz 分辨率通过 VGA 接口输出画面，支持 PS/2 键盘和板载按键双重输入。

| 项目 | 说明 |
|------|------|
| 主控芯片 | XC7K160TFFG676-1 |
| 系统时钟 | 100MHz（板载晶振） |
| 显示输出 | VGA 640×480 @ 60Hz |
| 画面刷新率 | 60 FPS |
| 输入设备 | 板载按键 + PS/2 键盘 + 拨码开关 |
| 显示设备 | VGA 显示器 + 7段数码管 + LED |

## 2. 硬件连接

### 2.1 VGA 连接

将 K7 开发板的 VGA 接口通过 VGA 线缆连接到显示器。VGA 信号为 12 位色深（RGB 各 4 位），支持 4096 种颜色。

### 2.2 PS/2 键盘

将 PS/2 键盘插入 K7 开发板的 PS/2 接口。注意：**必须在开发板上电前连接好键盘**，不支持热插拔。

### 2.3 板载按键

K7 开发板提供 5 个独立按键，功能如下：

| 按键 | FPGA 引脚 | 游戏中功能 |
|------|-----------|------------|
| BTN[0] | W14 | 上移 ↑ |
| BTN[1] | V14 | 下移 ↓ |
| BTN[2] | V19 | 左移 ← |
| BTN[3] | V18 | 右移 → |
| BTNX4 | W16 | 开火 / 开始游戏 |

### 2.4 拨码开关

SW[0] 用于选择游戏模式（见[第5节](#5-游戏模式)）。

---

## 3. 游戏启动

1. 将 `.bit` 文件下载到 K7 FPGA 开发板。
2. 按下 **全局复位键（rstn，引脚 W13）** 使系统进入初始状态。
3. 屏幕上将显示 **主菜单（MENU）** 界面。
4. 在菜单界面中按 **BTNX4 按键**或键盘 **J / 空格 / 回车** 开始游戏。

---

## 4. 操作方式

### 4.1 键盘操作（PS/2）

| 按键 | 功能 | 说明 |
|------|------|------|
| **W** | 上移 ↑ | 玩家飞机向上移动 |
| **A** | 左移 ← | 玩家飞机向左移动 |
| **S** | 下移 ↓ | 玩家飞机向下移动 |
| **D** | 右移 → | 玩家飞机向右移动 |
| **J** | 开火 | 发射子弹 |
| **空格** | 开火 | 发射子弹（同 J） |
| **回车** | 确认/开火 | 菜单中开始游戏，游戏中开火 |
| **P** | 暂停/继续 | 游戏中暂停或恢复（仅键盘） |
| **K** | 切换显示 | 切换 7 段数码管显示内容（仅键盘） |
| **1** | 选难度 | 菜单中切换难度为 **EASY**（仅键盘） |
| **2** | 选难度 | 菜单中切换难度为 **NORMAL**（仅键盘） |
| **3** | 选难度 | 菜单中切换难度为 **HARD**（仅键盘） |
| **4** | 选难度 | 菜单中切换难度为 **HELL**（仅键盘） |

### 4.2 板载按键操作

| 按键 | 功能 |
|------|------|
| **BTN[0]** | 上移 ↑ |
| **BTN[1]** | 下移 ↓ |
| **BTN[2]** | 左移 ← |
| **BTN[3]** | 右移 → |
| **BTNX4** | 开火 / 开始游戏 |

> **注意：** 暂停（P）、切换显示（K）、选择难度（1/2/3/4）只能通过键盘操作。按键和键盘可以同时使用，互相补充。

### 4.3 按键防抖

所有板载按键均经过硬件防抖处理（AntiJitter，4 帧确认），避免按键抖动造成的误触发。

## 5. 游戏模式

通过 **SW[0] 拨码开关** 在菜单界面选择：

| SW[0] | 模式 | 说明 |
|-------|------|------|
| 0（下拨） | **SCORE 模式** | 得分达到 **500 分**即通关获胜 |
| 1（上拨） | **ENDLESS 模式** | 无通关条件，尽量生存更久，追求最高分 |

> 模式只能在菜单界面切换。进入游戏后，SW[0] 的改变不会影响当前游戏进程。

---

## 6. 难度等级

在菜单界面通过键盘数字键 **1 / 2 / 3 / 4** 选择难度：

| 按键 | 难度 | 初始生命值 | 说明 |
|------|------|-----------|------|
| **1** | EASY | 3 | 适合新手，敌人弹幕较稀疏 |
| **2** | NORMAL（默认） | 3 | 标准难度 |
| **3** | HARD | 3 | 敌人攻击更频繁 |
| **4** | HELL | 2 | 地狱难度，一命高攻 |

难度主要影响敌人的生成频率、开火频率以及弹幕密度。

## 7. 游戏界面

### 7.1 主菜单（MENU）

```
┌──────────────────────────────────────────────────┐
│                                                  │
│            AEROPLANE                            │
│            DANMAKU SHOOTING                     │
│                                                  │
│            ┌──────────┐                         │
│            │  START   │  ← 黄色高亮             │
│            └──────────┘                         │
│                                                  │
│                  DIFFICULTY: EASY   ← 青色       │
│                  MODE:      SCORE   ← 绿色       │
│                                                  │
│                 PRESS START                      │
│                                                  │
└──────────────────────────────────────────────────┘
```

菜单界面显示：
- **游戏标题**（白色）：AEROPLANE / DANMAKU SHOOTING
- **START 按钮**（黄色）：提示开始游戏
- **难度显示**（青色）：当前选择的难度
- **模式显示**（绿色）：当前选择的游戏模式
- **提示文字**（灰色）：PRESS START

### 7.2 游戏画面（PLAYING）

游戏画面包含：
- **玩家飞机**：屏幕底部的三角形飞机（白色/闪烁=无敌状态）
- **敌机（UFO）**：从屏幕顶部生成，左右漂移并向下移动
- **玩家子弹**：从玩家飞机射出，向上飞行
- **敌方子弹**：从敌机射出，向下飞行
- **障碍物**：随机生成，缓慢下移，可被玩家子弹摧毁
- **HUD 信息**：
  - 左上角 **HP:X**（白色）：当前生命值
  - 右上角 **SCORE:XXXXXXXX**（白色）：当前得分显示区域（x=400, y=456）
  - 左下角 **7段数码管**：可切换显示击杀数/生命/分数

### 7.3 暂停界面（PAUSED）

- 画面冻结，右上角显示 **"||"（黄色暂停符号）**
- 按 **P 键** 或 **开火键** 恢复游戏（有约 4 秒冷却时间）

### 7.4 游戏结束（GAME OVER）

- 画面中央显示 **GAME OVER**（红色大字）
- 约 5 秒后自动返回主菜单

### 7.5 通关（WIN）

- 仅在 **SCORE 模式**下，得分达到 500 分时触发
- 画面中央显示 **YOU WIN**（绿色大字）
- 约 5 秒后自动返回主菜单

## 8. 游戏机制

### 8.1 玩家

| 属性 | 数值 |
|------|------|
| 飞机尺寸 | 宽约 32px，高约 24px（三角形） |
| 移动速度 | 2 像素/帧（约 120 px/s） |
| 默认生命 | 3（HELL 难度为 2） |
| 无敌时间 | 180 帧（约 3 秒），受伤后触发 |
| 开火冷却 | 基础 8 帧，随武器等级缩短 |

- 飞机移动范围限制在屏幕边界内（左右留 20px 边距，上下也有限制）。
- **受伤后**：扣除 1 生命值 → 飞机回到屏幕中央 → 进入无敌状态（飞机闪烁） → 清除全屏敌方子弹。
- **生命归零**：游戏结束。

### 8.2 玩家子弹

| 属性 | 数值 |
|------|------|
| 最大子弹数 | 16（同时存在） |
| 子弹速度 | 5 px/帧（约 300 px/s） |
| 基础发射 | 双发（左一发 + 右一发，间距 10px） |
| 武器等级 2 | 追加第三发（中央） |
| 武器等级 3 | 弹幕进一步增强 |

- 子弹飞出屏幕上边界后自动消失。
- 击中敌机或障碍物后子弹消失。

### 8.3 武器升级

| 击杀数 | 武器等级 |
|--------|----------|
| 0-9 | 等级 1（双发） |
| 10-19 | 等级 2（三发） |
| 20+ | 等级 3（满级） |

升级门槛每次翻倍（10 → 20 → 40 → ...）。满级后不再升级。

### 8.4 敌机

| 属性 | 数值 |
|------|------|
| 最大敌机数 | 8（同时存在） |
| 碰撞体积 | 约 28×20 px（椭圆形 UFO） |
| 生成间隔 | 约 2 秒 |
| 生命值 | 1（一击必杀） |
| 击中得分 | +5 分 + 1 击杀 |

- 敌机从屏幕顶部随机位置生成，缓慢下移并左右晃动。
- 飞出屏幕底部后自动消失。
- 每个敌机拥有独立的开火冷却时间。

### 8.5 敌方子弹

| 属性 | 数值 |
|------|------|
| 最大子弹数 | 64（每架敌机固定占用 8 个槽位） |
| 子弹速度 | 2 px/帧（约 120 px/s） |
| 发射模式 | 双发（左右各一发） |

- 敌方子弹向下直线飞行，飞出屏幕底部后消失。
- 受到伤害时，全屏敌方子弹会被清除。

### 8.6 障碍物

| 属性 | 数值 |
|------|------|
| 最大障碍物数 | 8 |
| 生成间隔 | 约 5 秒 |
| 三种尺寸 | 小（12px）、中（24px）、大（40px） |
| 四种形状 | 随机（圆形/方形/十字/菱形） |

- 障碍物缓慢下移。
- 玩家子弹击中障碍物后双方消失。
- 玩家飞机撞击障碍物 **直接死亡**（无视生命值）。
- 障碍物不会攻击，仅作为阻挡物存在。

### 8.7 碰撞检测

| 碰撞类型 | 结果 |
|----------|------|
| 玩家子弹 → 敌机 | 敌机消灭，+5 分，+1 击杀 |
| 玩家子弹 → 障碍物 | 障碍物消灭 |
| 敌方子弹 → 玩家 | 扣 1 HP，回到中央，无敌 3 秒，清屏 |
| 敌机机身 → 玩家 | 扣 1 HP 或死亡 |
| 障碍物 → 玩家 | **直接死亡** |

### 8.8 得分规则

| 来源 | 分值 |
|------|------|
| 击落敌机 | +5 分/架 |
| 生存奖励 | +1 分/秒 |

## 9. 7段数码管显示

板载 4 位 7 段数码管可以轮换显示三种信息。按键盘 **K 键** 切换：

| 模式 | 显示内容 | 小数点位置 |
|------|----------|------------|
| **KILLS（击杀数）** | 累计击杀敌机数量 | 无 |
| **LIVES（生命值）** | 当前剩余 HP | 无 |
| **SCORE（分数）** | 当前得分，显示低 16 位 | 第 4 位数码管 |

> 分数超过 4 位十进制数时，高位溢出部分通过 **LED[7:0]** 显示。

## 10. 作弊模式

将以下拨码开关拨至 **上拨（ON）位置**：

| 开关 | SW[0] | SW[1] | SW[2] | SW[3] | SW[4] | SW[5] | SW[6] | SW[7] | SW[8] | SW[9] | SW[10] | SW[11] | SW[12] | SW[13] | SW[14] | SW[15] |
|------|-------|-------|-------|-------|-------|-------|-------|-------|-------|-------|--------|--------|--------|--------|--------|--------|
| 状态 | **OFF** | **OFF** | **ON** | **ON** | **OFF** | **ON** | **OFF** | **ON** | **OFF** | **OFF** | **OFF** | **ON** | **OFF** | **ON** | **OFF** | **OFF** |

即：**SW[2]、SW[3]、SW[5]、SW[7]、SW[11]、SW[13] 为 ON，其余全部 OFF**。

作弊模式效果：
- **生命值提升至 7**
- **无敌（不受敌方子弹伤害）**

> 作弊模式仅在菜单界面开始新游戏时生效。

## 11. 常见问题

### Q1：按键没有反应？
- 确认板载按键经过防抖，按下需保持短暂时间。
- 确认 PS/2 键盘在上电前已连接。
- 按动 rstn 复位键重新初始化系统。

### Q2：VGA 无画面？
- 检查显示器是否支持 640×480 @ 60Hz 模式。
- 检查 VGA 线缆连接是否牢固。
- 确认 `.bit` 文件已正确下载。

### Q3：为什么按 P 键无法暂停？
- 暂停有约 **4 秒冷却时间**，暂停后需等待冷却结束才能再次操作暂停。
- 同样，恢复游戏后也需等待冷却。

### Q4：SCORE 模式下要多少分通关？
- 需要 **500 分**。按每架敌机 5 分 + 每秒 1 生存分计算，大约需要击落 60-80 架敌机。

### Q5：HP 为 3 但 HELL 难度只有 2？
- HELL 难度的设计理念即是"高难度低容错"，初始只有 2 生命值。其他难度均为 3。
