# 数字逻辑课程大作业：弹幕射击游戏

## 一. 开发平台

本大作业IDE为vivado 2025.1

使用开发板为K7,引脚约束文件`k7.xdc`已放入工作区

## 二. 游戏介绍

### 1.总体介绍

本工程完成的是一个弹幕射击游戏，玩家操控一个飞行器，发射子弹攻击随机创建的其他飞机，并躲避其他飞机的弹幕。

### 2.游戏设定

1.玩家：飞机，外形为一个三角形飞机（适当增加细节），发射的子弹为双条弹幕（左右两边对称的武器），弹道为直线型，每次发射一颗子弹。如果玩家消灭达到一定数量的飞机，则可以通过按按钮升级武器。

2.敌方：外星飞碟，外形近似于椭圆形（适当增加细节），单次发射的子弹为1-2条，（随难度上升而改变），发射子弹数为1-5颗（随难度改变而改变）。弹道为直线型（基础）和曲线型（进阶）。曲线型指子弹发射后，以发射点为坐标起点，按照给定的曲线轨迹运动。曲线轨迹包含：圆、抛物线（具体运动方程看实际情况设定。难度较低时飞碟不会左右移动，难度更大后会主动规律性左右移动。

3.游戏目标：可切换积分模式和无尽模式。积分模式；达到一定积分后游戏胜利 无尽模式：源源不断刷新敌人，没有尽头，直到玩家生命归零终止。

4.生命和伤害：玩家飞机和敌方飞碟都具有生命值，默认单发子弹伤害为1，敌方飞碟生命为1，但是随难度上升生命可能增加至3.玩家生命值为3（一般模式），在不同难度中，生命值不同。其中无尽模式固定为3点生命值。当生命值归零，游戏画面清空，屏幕中出现大写的GAME OVER。当玩家还有生命值时，清空所有弹幕（保留敌方飞船），并在底线中间位置复活。玩家复活后会闪动三下（一秒一次），闪动完成敌方飞碟重新开始攻击。

5.障碍物：中立单位，各种形状的石头，玩家飞机撞上去至少掉1生命，最多直接坠毁，玩家的子弹可以摧毁石头。石头的大小决定玩家撞上去的伤害和摧毁障碍物所需的子弹数。最少1发子弹，最多3发子弹。不同大小的石头会随着难度升高出现。无论多大的障碍物，和玩家飞机碰撞后都会消失，障碍物不会影响敌方的飞船或弹幕。

6.难度设定：初始一共四个等级，可以手动切换。难度影响玩家起始生命数和初始敌方强度。随着时间的增加，难度会逐步提升，带来敌人数量、生命、子弹数增加，以及更多更大的障碍物的出现。难度值通过一个系数决定，难度影响的因素都通过不同的函数利用一个系数计算出来。

### 3.游戏操作

1.游戏开始：游戏开始显示主界面菜单，按动BTNX0Y0-X0Y3四个键选择难度，也可通过键盘1/2/3/4选择难度；通过SW[0]的开关决定模式（积分还是无尽）。难度选择后，按动BTNX4Y3或键盘Enter/J/Space进入游戏。游戏开始后如果要暂停，按动BTNX0Y0或键盘P。

2.玩家：通过BTNX0Y0-BTNX4Y3实现前后左右移动和开火。移动采用BTNX3Y0,BTNX4Y1,BTNX3Y2,BTNX2Y1四个键控制，开火由BTNX4Y3控制。也可使用键盘W/A/S/D控制上/左/下/右移动，J/Space/Enter开火，K升级武器。

3.计分：当前击毁敌军数、玩家当前生命、玩家积分 通过四位数码管SEGMENT[7:0],每个数码管的激活通过使能AN[3:0]激活。单个数码管功能参照DispNum.v。如果需要切换显示内容，通过按动BTNX1Y3实现，三者循环显示。注意：击毁敌军数不管击毁什么难度的敌军都算1个。由于数码管仅有四位，所以计数超过9999时，只保留后四位，超过9999的部分通过LED[7:0]用二进制方式表示，例如123456的显示方法为：数码管显示3456，LED用二进制表示12，即LED[7:0] = 00001100,LED[2]和[3]点亮其他不亮，如果还超出则全部清零重新显示。

4.作弊模式：当检测到SW[2],SW[3],SW[5],SW[7],SW[11],SW[13]这六个0-15的质数标号的开关为1，SW[1]到SW[14]其他按键为0时激活，此时生命值无限，即无论如何不会被击毁。

### 4.游戏显示

1.主界面：把vivado的bitstream导入板子以后显示的初始界面。背景为纯黑，中间用彩色横竖条圈出一块区域。在圈出区域的中间位置有本游戏名：Aeroplane Danmaku Shooting的大写，全英文，彩色，下面有一个方框，上面写着：START，右下角有一片区域，写着一行字：difficulty:easy/normal/hard/hell（均大写），表示难度，按动难度选择键会改变难度显示。难度显示这一行下面有个MODE:SCORE/Endless（全大写），通过判断SW[0]的状态决定显示积分模式还是无尽模式

2.进入游戏后，前五秒不刷新任何敌人/障碍物。右下角加一个数字显示：SCORE:00000000，用作分数显示。每次击毁的敌人生命值是x，就加5*x分，障碍物摧毁不得分。如果玩家没有被摧毁，游戏每进行1秒就额外加1分生存分。

3.暂停：按动暂停键以后，整个游戏所有内容全部停下，包括子弹、障碍物、敌军和玩家的飞行器和子弹。在右下角显示一个表示暂停的 “ || ”符号。再次按动暂停键，暂停符号变为三角形的开始符号，3s后消失。暂停每五秒最多暂停一次。

4.游戏结束：当玩家被摧毁时，清空所有内容并用红色大写英文字母写：GAME OVER，分两行，居中。显示5秒后回到主界面。如果玩家积分模式达到指定分数且生命不为0，则显示绿色大字YOU WIN，五秒后回到主界面。

## 三. 技术架构与状态机

### 1. 模块层次

```
top.sv                   # 顶层芯片：时钟分频、去抖、模块互联、IO 绑定

├── vga_top.sv           # VGA 渲染顶层：组合渲染 + 优先级 MUX
│   ├── player_render    # 玩家飞机渲染
│   ├── enemy_render[]   # 敌方 UFO 渲染（多实例）
│   ├── obstacle_render[]# 障碍物石头渲染（多实例）

├── bullet_pool.sv       # 子弹池（统一管理玩家弹与敌弹）
```

### 2. 游戏状态机 (game_fsm)

| 状态       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| `MENU`     | 初始状态。显示主菜单界面。等待难度选择和开始按键             |
| `PLAY`     | 游戏进行中。生成敌人/障碍物、更新实体、处理碰撞、计分        |
| `PAUSE`    | 暂停状态。所有实体停止更新，显示暂停标志。再次按暂停键恢复   |
| `GAMEOVER` | 玩家生命归零。显示红色 GAME OVER，5 秒后返回 MENU            |
| `WIN`      | 积分模式达到目标分数。显示绿色 YOU WIN，5 秒后返回 MENU      |

状态转移：
- `MENU → PLAY`：BTNX4Y3 按下且难度已选择
- `PLAY → PAUSE`：BTNX0Y0 按下（5 秒内最多一次）
- `PAUSE → PLAY`：BTNX0Y0 按下，3 秒倒计时后恢复
- `PLAY → GAMEOVER`：玩家 lives == 0
- `PLAY → WIN`：积分模式 && score >= target_score
- `GAMEOVER → MENU`：5 秒后自动
- `WIN → MENU`：5 秒后自动

### 3. 帧节拍系统

- 系统时钟：100MHz → `clk_100m`
- VGA 像素时钟：25MHz = `clkdiv[1]`（100MHz / 4）
- 帧节拍 `frame_tick`：在 `vgac.vs` 下降沿产生，约 60Hz
- 所有游戏逻辑更新（移动、生成、碰撞、计分）在 `frame_tick` 有效时进行
- 数码管扫描用独立的 1kHz 左右扫描时钟

### 4. 子弹系统

- `bullet_pool` 统一管理所有子弹，维护一个固定大小的子弹槽位数组
- 每颗子弹属性：active, x, y, dx, dy, type(PBULLET/EBULLET), traj(LINE/CIRC/PARA), life(存活帧数)
- 玩家开火：`player.fire_pulse` 触发，从 muzzle_lx/muzzle_rx/muzzle_y 位置创建两颗 PBULLET
- 敌机开火：`enemy.fire_req` 触发，在 fire_x/fire_y 位置创建 EBULLET，按 fire_traj/fire_count/fire_dual 参数生成
- 子弹移动每帧更新：直线弹道 dx/dy 恒定；曲线弹道根据运动方程逐帧计算偏移
- 子弹飞出屏幕（y<0 或 y>=480 或 x<0 或 x>=640）自动回收

## 四. 计分与难度系统

### 1. 计分规则

| 项目           | 分数       |
| -------------- | ---------- |
| 击毁敌机       | 5 × 敌机HP |
| 摧毁障碍物     | 0          |
| 生存奖励       | 1 分/秒    |
| 积分模式目标   | 暂定 500   |
| 无尽模式       | 无目标上限 |

### 2. 难度系数公式

定义难度基础系数 `D`：
- Easy: D=1.0
- Normal: D=1.5
- Hard: D=2.0
- Hell: D=3.0

随时间增长系数 `T(t)`（t 为游戏进行秒数）：
- 积分模式: T(t) = 1 + floor(t/30) × 0.1
- 无尽模式: T(t) = 1 + floor(t/15) × 0.1

实际难度乘数: `M = D × T(t)`

影响项目：
- 敌人刷新间隔: `base_spawn_interval / M`
- 敌人 HP: `clamp(ceil(1 × M), 1, 3)`
- 敌人子弹数: `clamp(ceil(2 × M), 1, 5)`
- 敌人发射周期: `base_fire_period / M`
- 障碍物刷新率: 随 M 增大增加 M/L 尺寸出现概率

## 五. VGA 渲染规范

- 详见 `ZJUVGA.md`（同目录下的 VGA 接口文档）
- 所有 `*_render` 模块必须是纯组合逻辑，不得包含时钟/计数
- 颜色位序：`{B[3:0], G[3:0], R[3:0]}`（BGR 序，不是 RGB）
- 消隐期（rdn==1）时 vga_data 强制输出 12'h000
- 多实体优先级：HUD > 玩家 > 玩家子弹 > 敌弹 > 敌人 > 障碍物 > 背景

## 六. K7 板卡引脚绑定

详见 `K7.xdc` 约束文件。关键信号：
- 100MHz 时钟: AC18
- 复位: W13 (低有效)
- VGA: r[3:0]/g[3:0]/b[3:0]/hs(M22)/vs(M21)
- 按钮: BTNX0Y0..X4Y3 (4组×4个)
- PS/2键盘: ps2_clk / ps2_data
- 开关: SW[15:0]
- LED: LED[7:0]
- 数码管: SEGMENT[7:0], AN[3:0]
